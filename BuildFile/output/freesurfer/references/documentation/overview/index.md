# FreeSurfer

<span id="line-5" class="anchor"></span>

<span id="line-6" class="anchor"></span>

FreeSurfer is a software package for the analysis and visualization of
structural and functional neuroimaging data from cross-sectional or
longitudinal studies. It is developed by the
<a href="https://www.martinos.org/lab/lcn" class="https">Laboratory for
Computational Neuroimaging</a> at the
<a href="http://martinos.org/" class="http">Athinoula A. Martinos Center
for Biomedical Imaging.</a> FreeSurfer is the structural MRI analysis
software of choice for the <a
href="https://github.com/Washington-University/Pipelines/wiki/v3.4.0-Release-Notes,-Installation,-and-Usage"
class="https">Human Connectome Project.</a> <span id="line-7"
class="anchor"></span><span id="line-8" class="anchor"></span>

# Our tools

<span id="line-35" class="anchor"></span>

### Structural MRI

<span id="line-36" class="anchor"></span>

FreeSurfer provides a full processing stream for structural MRI data,
including: <span id="line-37" class="anchor"></span><span id="line-38"
class="anchor"></span>

- Skull stripping, B1 bias field correction, and gray-white matter
  segmentation <span id="line-39" class="anchor"></span>
- Reconstruction of cortical surface models (gray-white boundary surface
  and pial surface) <span id="line-40" class="anchor"></span>
- Labeling of regions on the cortical surface, as well as subcortical
  brain structures <span id="line-41" class="anchor"></span>
- Nonlinear registration of the cortical surface of an individual with a
  stereotaxic atlas <span id="line-42" class="anchor"></span>
- Statistical analysis of group morphometry differences
  <span id="line-43" class="anchor"></span><span id="line-44"
  class="anchor"></span>

### Diffusion MRI

<span id="line-66" class="anchor"></span>

\* **[TRActs Constrained by UnderLying Anatomy
(TRACULA):](https://surfer.nmr.mgh.harvard.edu/fswiki/Tracula)** TRACULA
is a tool for automated global probabilistic tractography with
anatomical priors. It reconstructs a set of major white-matter pathways
by incorporating prior information on the structural segmentation labels
that each pathway goes through or next to, as a function of position
along the length of the pathway. It includes a specialized stream for
processing longitudinal diffusion MRI data. <span id="line-67"
class="anchor"></span><span id="line-68" class="anchor"></span>

\*
**[AnatomiCuts](https://surfer.nmr.mgh.harvard.edu/fswiki/AnatomiCuts)**
: An unsupervised hierarchical streamline clustering algorithm based on
anatomical similarity.
[AnatomiCuts](https://surfer.nmr.mgh.harvard.edu/fswiki/AnatomiCuts) is
currently in the developing branch
(<a href="https://github.com/freesurfer/freesurfer/tree/dev/anatomicuts"
class="https">https://github.com/freesurfer/freesurfer/tree/dev/anatomicuts</a>).
<span id="line-69" class="anchor"></span><span id="line-70"
class="anchor"></span>

\*
**[DiffusionTool](https://surfer.nmr.mgh.harvard.edu/fswiki/DiffusionTool)**
: This tool can help generating the configuration file of TRACULA and
setting up the parameters to run
[AnatomiCuts](https://surfer.nmr.mgh.harvard.edu/fswiki/AnatomiCuts).
The
[DiffusionTool](https://surfer.nmr.mgh.harvard.edu/fswiki/DiffusionTool)
is currently in the developing branch (<a
href="https://github.com/freesurfer/freesurfer/tree/dev/diffusion_tool"
class="https">https://github.com/freesurfer/freesurfer/tree/dev/diffusion_tool</a>).
<span id="line-71" class="anchor"></span><span id="line-72"
class="anchor"></span>
