# FreeSurfer Support

<span id="line-2" class="anchor"></span>

Have you encountered an error while running a FreeSurfer tool? Please
follow these steps to get help: <span id="line-3"
class="anchor"></span><span id="line-4" class="anchor"></span>

1.  **Search the archives:** It is highly likely that someone else has
    run into the same problem before you. The fastest way to get answers
    is therefore to
    <a href="http://www.mail-archive.com/freesurfer@nmr.mgh.harvard.edu/"
    class="http">search the archives</a> of our mailing list.
    <span id="line-5" class="anchor"></span><span id="line-6"
    class="anchor"></span>

2.  **Ask a question:** If you cannot find an answer in the archives,
    <a href="https://mail.nmr.mgh.harvard.edu/mailman/listinfo/freesurfer"
    class="https">subscribe</a> to the list and ask a question. You can
    help us help you faster by following some simple guidelines on [how
    to describe your
    problem](https://surfer.nmr.mgh.harvard.edu/fswiki/BugReporting).
    <span id="line-7" class="anchor"></span><span id="line-8"
    class="anchor"></span>

    1.  **FreeSurfer mailing list**
        (`<freesurfer AT nmr DOT mgh DOT harvard DOT edu>`): This is the
        list to email for general support on installing and using
        FreeSurfer. You need to
        <a href="https://mail.nmr.mgh.harvard.edu/mailman/listinfo/freesurfer"
        class="https">subscribe</a> to the list before you can send
        messages to it, and you need to send your messages from the
        email address with which you subscribed. (This prevents spam.)
        Messages sent to this list are read by the FreeSurfer developers
        and user community. All questions and responses are
        <a href="http://www.mail-archive.com/freesurfer@nmr.mgh.harvard.edu/"
        class="http">archived</a>. <span id="line-9"
        class="anchor"></span><span id="line-10" class="anchor"></span>

    2.  **Mailing lists for third-party tools:** For problems with other
        tools and libraries used by FreeSurfer, please contact the
        respective mailing list: <span id="line-11"
        class="anchor"></span>

        - <a href="http://www.fmrib.ox.ac.uk/fsl/" class="http">FMRIB Software
          Library (FSL)</a>.
          (<a href="http://www.jiscmail.ac.uk/cgi-bin/webadmin?REPORT&amp;z=3"
          class="http">Subscribe</a> \|
          <a href="http://www.jiscmail.ac.uk/lists/fsl.html"
          class="http">Archives</a>) <span id="line-12"
          class="anchor"></span>

        - <a href="http://www.bic.mni.mcgill.ca/software/" class="http">The BIC
          Brain Imaging Software Toolbox (MNI).</a>
          (<a href="http://www.bic.mni.mcgill.ca/mailman/listinfo/minc-users"
          class="http">Subscribe</a> \|
          <a href="http://www.bic.mni.mcgill.ca/pipermail/minc-users/"
          class="http">Archives</a>) <span id="line-13"
          class="anchor"></span><span id="line-14"
          class="anchor"></span>

3.  **Exchange files:** If the FreeSurfer team asks you to upload
    additional data files to help troubleshoot the problem, you can do
    so via
    <a href="https://surfer.nmr.mgh.harvard.edu/fswiki/FtpFileExchange"
    class="nonexistent">FTP.</a> <span id="line-15"
    class="anchor"></span><span id="line-16" class="anchor"></span>

4.  **Contribute what you learned**: Once you figure out how to solve a
    problem that has not been documented previously, you can add
    documentation to help everyone else! To contribute to these wiki
    pages, you will need a
    [WikiUserName](https://surfer.nmr.mgh.harvard.edu/fswiki/WikiUserName).
    Please see
    [GettingAccess](https://surfer.nmr.mgh.harvard.edu/fswiki/GettingAccess)
    to obtain a
    [WikiUserName](https://surfer.nmr.mgh.harvard.edu/fswiki/WikiUserName)
    and then document away. To create a new page once you have an
    account, just goto the URL you want to create. For instance, goto
    this link for a page you would name MyNewPage:
    <a href="https://surfer.nmr.mgh.harvard.edu/fswiki/MyNewPage"
    class="https">https://surfer.nmr.mgh.harvard.edu/fswiki/MyNewPage</a>
    and note the link that says 'Create new empty page'. Just click on
    that and type away (but please don't use MyNewPage as a page name!).
    <span id="line-17" class="anchor"></span>
