# How To: Save Glm To Bids Glm Report No Contrast

**Difficulty**: Advanced
**Estimated Time**: 15 minutes
**Tags**: pytest, workflow, integration

## Overview

Workflow: Run generate_report with no contrasts after save_glm_to_bids.

generate_report tries to rely on some of the generated output,
if no contrasts are requested to generate_report
then it will rely on the content of
model._reporting_data["filenames"]

report generated by save_glm_to_bids should contain relative paths
to the figures displayed as the report and its figures are meant
to go together

report generated after using save_glm_to_bids could be saved anywhere
so evengthough we reuse pre-generated figures,
we will rely on full path in this case

## Complete Example

```python
# Setup
# Fixtures: two_runs_model, tmp_path

# Workflow
'Run generate_report with no contrasts after save_glm_to_bids.\n\n    generate_report tries to rely on some of the generated output,\n    if no contrasts are requested to generate_report\n    then it will rely on the content of\n    model._reporting_data["filenames"]\n\n    report generated by save_glm_to_bids should contain relative paths\n    to the figures displayed as the report and its figures are meant\n    to go together\n\n    report generated after using save_glm_to_bids could be saved anywhere\n    so evengthough we reuse pre-generated figures,\n    we will rely on full path in this case\n    '
contrasts = {'BBB-AAA': 'BBB-AAA'}
contrast_types = {'BBB-AAA': 't'}
model = save_glm_to_bids(model=two_runs_model, contrasts=contrasts, contrast_types=contrast_types, out_dir=tmp_path, **KWARGS)
assert model._reporting_data.get('filenames', None) is not None
EXPECTED_FILENAMES = ['run-1_design.png', 'run-1_corrdesign.png', 'run-1_contrast-bbbMinusAaa_design.png']
with (tmp_path / 'report.html').open('r') as f:
    content = f.read()
    assert 'BBB-AAA' in content
    for file in EXPECTED_FILENAMES:
        assert f'src="{file}"' in content
report = model.generate_report(**KWARGS)
report.save_as_html(tmp_path / 'new_report.html')
assert 'BBB-AAA' in report.__str__()
for file in EXPECTED_FILENAMES:
    assert f'src="{tmp_path / file}"' in report.__str__()
    assert f'src="{file}"' not in report.__str__()
```
