# FreeSurfer File Formats

<span id="line-4" class="anchor"></span>

[FreeSurfer](https://surfer.nmr.mgh.harvard.edu/fswiki/FreeSurfer)
creates its own file formats for storing and manipulating volumetric,
surface and transform data, including mgh, mgz, gca, bshort, bfloat,
COR, surface, curv, w, annot, patch, gcs, dat, xfm, m3d and lta. These
[FreeSurfer](https://surfer.nmr.mgh.harvard.edu/fswiki/FreeSurfer)
native formats are summarized below, along with some closely-related
external image formats. <span id="line-5"
class="anchor"></span><span id="line-6" class="anchor"></span>
