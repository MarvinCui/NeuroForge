# FreeSurfer Tutorials

<span id="line-26" class="anchor"></span>

The FreeSurfer tutorials provided below are designed to give users an
introduction to using FreeSurfer, as well as get you acquainted with the
concepts needed to perform its various modes of analysis and processing
of MRI data. The tutorials are designed to be followed along in a
terminal window, where commands can be copy/pasted into the terminal
window instead of typed. <span id="line-27"
class="anchor"></span><span id="line-28" class="anchor"></span>

In order to run any of the FreeSurfer tutorials, you must have a valid
[FreeSurfer](DownloadAndInstall.html) installation on your machine, and
a local copy of the [tutorial
data](https://surfer.nmr.mgh.harvard.edu/fswiki/FsTutorial/Data). Be
sure to set the **TUTORIAL_DATA** environment variable properly as
specified on the [tutorial
data](https://surfer.nmr.mgh.harvard.edu/fswiki/FsTutorial/Data) page.
<span id="line-29" class="anchor"></span><span id="line-30"
class="anchor"></span>
