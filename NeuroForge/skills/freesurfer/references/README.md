# FreeSurfer Reference Map

This directory contains a local snapshot of FreeSurfer wiki documentation used by the `freesurfer` Codex skill. Keep `SKILL.md` operational and compact; place source documentation and supporting summaries here.

## Documentation

- `documentation/documentation_index.json`: inventory of captured documentation files.
- `documentation/overview/FreeSurferWiki.md`: project overview and links to installation, tutorials, citations, and support.
- `documentation/overview/DownloadAndInstall.md`: release/download notes, license, platform notes, and version consistency warning.
- `documentation/overview/QuickInstall.md`: moved page; use `DownloadAndInstall.md`.
- `documentation/overview/ReconAllTable.md`: explains recon-all processing tables and points to subject-specific `scripts/recon-all.log`.
- `documentation/overview/ReconAllTableStableV6.0.md`: stable FreeSurfer v6.0 recon-all step table with inputs, commands, and outputs.
- `documentation/overview/FAQ.md`: common questions, troubleshooting, output interpretation, and analysis guidance.
- `documentation/overview/FileFormats.md`: FreeSurfer native and related external formats.
- `documentation/overview/Glossary.md`: definitions of common FreeSurfer volume, surface, label, segmentation, and topology terms.
- `documentation/overview/CoordinateSystems.md`: coordinate-system formulas and use cases.
- `documentation/overview/FreeSurferCommandsRegistration.md`: registration command overview.
- `documentation/overview/FreeSurferMethodsCitation.md`: method descriptions and citations.
- `documentation/overview/FreeSurferSupport.md`: support channels and mailing-list guidance.
- `documentation/overview/Tutorials.md`: tutorial/course information.

## Dependency Metadata

The `dependencies/` files were produced by a generic code-analysis pass. This skill is documentation-oriented, so those files are not primary sources for FreeSurfer behavior.
